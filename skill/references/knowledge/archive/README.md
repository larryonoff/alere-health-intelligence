# Imported Archive

These files preserve extracted text for editorial review. They are not approved
runtime references.

Do not use them directly in a user response. To promote a recipe:

1. identify the complete recipe block;
2. separate ingredients from preparation;
3. preserve explicit quantities;
4. mark missing servings or time as `unknown`;
5. remove promotional and health-outcome language;
6. check the result against safety rules;
7. add a structured Markdown file under `runtime/recipes/`;
8. add its ID to `runtime/recipe-index.md`;
9. run `skill/scripts/validate-knowledge.rb`.
